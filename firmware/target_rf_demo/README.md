# M2-R2 – Target ESP32/Wokwi CÔ LẬP chạy RF proxy M2-R1 (không phải firmware production)

**Phạm vi:** chạy đúng model C99 do `python -m ml.train.rf_demo_m2r1` sinh (RELATIVE_HIGH_ROLL proxy nhị phân, train trên Hohai đã xử lý, held-out `hohai|T9`). KHÔNG phải bộ phân loại 4 lớp đã kiểm chứng, KHÔNG tương thích tiền xử lý IMU production, KHÔNG đăng ký `svmg_engine_set_rf()`, KHÔNG thay Baseline B/alarm, NEG ≠ NORMAL, không đọc MPU6050 trực tiếp, không phát hiện nguy hiểm hàng hải.

**Build:** `cd firmware/target_rf_demo && ../../.venv/bin/pio run`. `prepare_model.py` chạy exporter M2-R1 nếu thiếu artifact (gitignored `ml/data/models/rf_demo_m2r1/`), kiểm SHA-256 model khớp `results.json`, rồi biên dịch `svmg_rf_proxy_demo.c` vào firmware.

**Wokwi + replay:** VS Code → `Wokwi: Start Simulator` với `firmware/target_rf_demo/wokwi/wokwi.toml` (RFC2217 cổng 4000; đóng simulator HV01 trước vì cùng cổng — nhận byte `53 56` "SV" nghĩa là cổng đang phục vụ firmware HV01), rồi từ repo root: `.venv/bin/python -m ml.export.rf_demo_replay --port rfc2217://localhost:4000 --run-id wokwi01` (ESP32 thật: `--port /dev/cu.usbserial-…`). Kết quả, transcript và SHA-256 ghi vào `ml/data/models/rf_demo_m2r1/esp32_replay/<run-id>/` (gitignored). Chỉ `execution_kind=wokwi_simulation` mới cho `WOKWI_PASS`.

**Protocol v1 (tách khỏi protocol HV01):** frame `52 46 | version:u8=1 | type:u8 | len:u16 | payload | crc32:u32`, little-endian, CRC-32/ISO-HDLC trên `version..payload`. Host→target: `01 PREDICT` = `sample_id:u32, count:u8 (≤32), f32[count]` (len phải = 5+4·count, tối đa 133 B); `02 HELLO_REQ` rỗng. Target→host: `80 HELLO` (protocol, số feature/cây/nút, model_version, SHA-256 model, SHA-256 thứ tự feature, target, chip, MHz); `81 RESULT` = `sample_id:u32, status:i8, pred:i8, score:f32, elapsed_us:u32`; `8F ERROR` = `code:u8` (1 sync, 2 CRC, 3 version, 4 length, 5 payload, 6 timeout 1 s/byte, 7 type). Mỗi request nhận đúng một RESULT/ERROR; sau lỗi firmware xả input tới khi im 50 ms. `status`: 0 OK, −2 sai số feature, −3 NaN/Inf; khi status ≠ 0 thì `pred = −1` (không bao giờ thành NEG). `elapsed_us` chỉ đo lời gọi `svmg_rf_proxy_demo_predict()`; bộ đệm tĩnh, không cấp phát động.
